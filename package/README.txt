Cold Waters MP - 1v1 submarine duels for Cold Waters + DotMod

Extract everything in this zip into your Cold Waters folder (the one with ColdWaters.exe).
Full instructions, keys and troubleshooting: https://github.com/RafJansen-AI/cold-waters-mp

Uninstall: delete winhttp.dll, doorstop_config.ini, .doorstop_version and the BepInEx folder.
No game file is changed.
